Simple Hashing

Digite um nome. O programa transforma o texto em um código curto, passo a passo. O mesmo nome sempre dá o mesmo código.

Versão para navegador. O programa original é um notebook em Python. Esta página refaz a mesma conta e dá o mesmo resultado que o script, inclusive o sorteio com semente fixa.

1 Cada letra vira um número

Cada caractere tem um número no padrão Unicode (ord em Python).

2 Multiplica todos os números

O resultado é enorme: 0 dígitos.

3 Sorteia um número com semente fixa

Com a mesma semente, o "sorteio" repete sempre o mesmo valor. Aqui sai um inteiro entre o tamanho do nome e 2.000.000.

4 Mistura os dois com XOR e mostra em hexadecimal

O programa mostra só os primeiros 16 caracteres. A parte em cinza é cortada.

Resultado

Repare que o sorteio só altera os últimos dígitos, que ficam na parte cortada. Por isso é um exercício para aprender, não um hash seguro como os usados em senhas.
