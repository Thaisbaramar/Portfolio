SkyCast

App de previsão do tempo. Toque numa cidade para ver o clima, arraste para o lado para ver as outras e abra os detalhes com hora a hora, nascer e pôr do sol.

Versão para navegador. O app original é feito em Flutter (para celular) e busca o clima de verdade na API OpenWeather. Aqui os números são de exemplo. O logo e a animação de carregamento são os arquivos do projeto. Os textos do app estão em inglês, como no original.

O que testar

  • Pesquise uma cidade (ex.: Paris, Tokyo) e toque nela para ver a prévia e adicionar.
  • Arraste um cartão para a esquerda para apagar (ou use a tecla Delete com o cartão selecionado).
  • No menu …, troque °C/°F e abra Units para vento e pressão. A escolha fica salva neste navegador.
