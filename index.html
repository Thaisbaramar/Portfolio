A weather forecast app built as a group project, using the OpenWeather API. It shows current conditions and a multi-day forecast, and lets the user keep a list of cities.

  • Animação própria para cada condição: sol, nuvens, chuva, neve, trovoada e vento.
  • Detecta perda de conexão e mostra uma tela de "sem internet".
  • O JSON da API é convertido em um isolate separado (compute), para não travar a interface.
  • Calls the One Call API 3.0 and the Geocoding API to look up cities by name.
  • Saved cities stored locally with SQLite (sqflite); device location through geolocator.
  • A dedicated animation for each condition: sun, clouds, rain, snow, thunderstorm and wind.
  • Detects lost connectivity and shows a "no internet" screen.
  • API JSON is parsed in a separate isolate (compute) to keep the UI smooth.

Future<WeatherData?> fetchWeather(double lat, double lon) async {
  try {
    final response = await http.get(
      Uri.parse('$baseUrl?lat=$lat&lon=$lon&appid=$apiKey'),
    );
    if (response.statusCode == 200) {
      // parse in a separate isolate
      return compute(parseWeatherData, response.body);
    } else {
      throw Exception('Failed to load weather data');
    }
  } catch (e) {
    return null;
  }
}

Sistema de agendamento de consultas odontológicas com interface gráfica. Paciente, dentista, secretária e equipe entram com contas diferentes e cada uma tem um nível de acesso.

A dental appointment scheduling system with a graphical interface. Patient, dentist, secretary and staff sign in with different accounts, each with its own level of access.

  • Quatro tipos de conta (CLIENT, DENTIST, SECRETARY, STAFF) com permissões definidas em um só lugar e conferidas na camada de dados, não só nos botões.
  • O paciente vê e marca só as próprias consultas. A secretária vê a agenda toda, marca e cancela para qualquer paciente e cadastra pacientes.
  • O dentista confirma ou cancela uma consulta (com motivo) e o paciente recebe um aviso no sistema.
  • Calendário, horários por data, dados gravados em arquivos de texto e testes automáticos das regras de acesso.
  • Uso de ExecutorService para carregar os dados fora da thread da interface.
  • Four account types (CLIENT, DENTIST, SECRETARY, STAFF) with permissions defined in one place and checked in the data layer, not only on the buttons.
  • A patient sees and books only their own appointments. The secretary sees the whole schedule, books and cancels for any patient and registers patients.
  • The dentist confirms or cancels an appointment (with a reason) and the patient gets an in-app notice.
  • Calendar, time slots by date, data saved to text files, and automated tests for the access rules.
  • Uses ExecutorService to load data off the UI thread.

Shipping Company

Ver demonstração →Try the demo →

Calculadora de frete. O usuário monta o pedido com produtos de informática e o programa decide quantos contêineres grandes e pequenos são necessários e quanto custa o envio.

A shipping calculator. The user builds an order from computer products and the program decides how many big and small containers are needed, and what the shipment costs.

  • Modelagem com herança: classe abstrata Container, com BigContainer (2,59 × 2,43 × 12,01 m) e SmallContainer (metade do comprimento).
  • Soma volume e peso do pedido e escolhe a combinação de contêineres; o preço depende do peso total.
  • Interface JavaFX com tela de abertura animada, resumo do pedido e navegação Voltar, Próximo e Recomeçar.
  • Projeto Maven, com JAR gerado.
  • Inheritance-based model: abstract Container, with BigContainer (2.59 × 2.43 × 12.01 m) and SmallContainer (half the length).
  • Adds up the order's volume and weight and picks the container mix; the price depends on total weight.
  • JavaFX interface with an animated splash screen, order preview and Back, Next and Restart navigation.
  • Maven project, with a built JAR.

public abstract class Container {
    public ArrayList<Item> items;
    public double[] size;
    public int weightCapacity;
    public int price;
    protected abstract double getVolume();
}

public class BigContainer extends Container {
    public BigContainer() {
        super(new double[]{2.59, 2.43, 12.01}, Integer.MAX_VALUE, 1800);
    }
    @Override
    public double getVolume() {
        return size[0] * size[1] * size[2];
    }
}

Simple Hashing

Ver demonstração →Try the demo →

Exercício introdutório sobre funções de hash. Transforma um nome em um código hexadecimal de tamanho fixo, sempre o mesmo para a mesma entrada.

An introductory exercise on hash functions. It turns a name into a fixed-length hexadecimal code, always the same for the same input.

  • Converte cada caractere em seu valor Unicode e multiplica todos (math.prod).
  • Faz XOR do produto com um inteiro pseudoaleatório de semente fixa (random.seed(2)), o que torna o resultado reproduzível.
  • Mostra o resultado em hexadecimal, cortado em 16 caracteres.
  • É um exercício didático e não um hash criptográfico.
  • Converts each character to its Unicode value and multiplies them all (math.prod).
  • XORs the product with a pseudo-random integer from a fixed seed (random.seed(2)), which keeps the result reproducible.
  • Prints the result in hexadecimal, cut to 16 characters.
  • A teaching exercise, not a cryptographic hash.

def convert(_):
    for i in range(0, len(name)):
        li[i] = ord(name[i])
    product = math.prod(li)
    random.seed(2)
    p = random.randint(len(li), 2000000)
    xor = hex(product ^ p)
    print(xor[:16])
