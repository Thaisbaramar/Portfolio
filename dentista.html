Dentist Appointment Calendar

Um computador de mentira com o programa aberto. Entre como paciente, secretária ou dentista e veja que cada um tem acesso diferente. O paciente marca, a secretária organiza a agenda e o dentista confirma ou cancela e avisa o paciente.

Versão para navegador. O programa original é um aplicativo de computador em Java (Swing). Aqui as janelas, textos, permissões e mensagens seguem o código. Os dados ficam salvos só neste navegador, como o programa original grava em arquivos. As consultas agora são guardadas por data (no código original não diferenciavam os dias).
